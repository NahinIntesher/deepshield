This folder contains the original `best_model.pth` checkpoint and sample videos. The checkpoint is 618,147,845 bytes (589.51 MiB). Its verified SHA-256 and hosting model card are in `hosting/`.

This is a custom Swin-Small + DCT + temporal transformer model. Use the matching Backend model and preprocessing code to run inference. Uploading the checkpoint to storage does not deploy a prediction API.
